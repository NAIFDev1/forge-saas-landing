# Forge — Build. Ship. Scale.

A premium landing page for **Forge**, a fictional developer platform that brings building, testing, debugging, and deploying into one workflow. Built as a modern single-page frontend project.

![Forge](public/favicon.svg)

## Overview

Forge is a showcase landing page for a developer tool with a dark, technical-first aesthetic. It models a full product narrative — from a powerful CLI and interactive terminal to a live deployment workflow, a developer dashboard, code/API integrations, changelog, and pricing.

## Features

- **Sticky navigation** with announcement banner, mobile menu, and GitHub CTA.
- **Animated hero** with a scripted terminal simulation and one-click copy of `npm install -g forge-cli`.
- **Ecosystem strip** of developer-facing integrations.
- **Feature grid** covering CLI, deployments, logs, environments, API, and teams.
- **Interactive CLI section** with clickable commands that render realistic terminal output.
- **Git workflow** showing build → tests → preview → production with animated pipeline.
- **Developer dashboard** mock with health metrics, request graph, build history, and live logs.
- **Code integration** with syntax-highlighted samples and language tabs.
- **API section** with Request / Response / JavaScript / cURL tabs and copy support.
- **Changelog**, **pricing tiers (Free / Pro / Team)**, **FAQ accordion**, and a closing CTA.
- Honours `prefers-reduced-motion` and has no console errors.

## Tech Stack

- React 18 + Vite 5
- Tailwind CSS 3 (custom dark design tokens)
- shadcn/ui-style primitives (Radix Accordion, Slot, CVA)
- Lucide React icons
- Framer Motion animations

## Getting Started

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev
```

Open the printed URL (default `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

`npm run build` outputs a production bundle to `dist/`.
